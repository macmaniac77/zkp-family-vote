What “hash signing” means on this page

1
Public context

Election id, candidate list, and the frozen public-key ring. Anyone can have this file — it contains no secrets.

2
Local secret

Your sk stays in memory (paste, vault unlock, or file). It is used only inside this tab to build the ring signature.

3
Message & hash

Ballot message: vote|electionId|choice|keyImage. We display SHA-256(message) so you can see the digest you are binding to. The LSAG signature proves a ring member authorized that message; the key image prevents a second ballot.
